Каталог проектов

Подборка разработанных систем автоматизации, интеллектуальных ботов и утилит для серверного администрирования.

dns

ZX Server Panel

Полнофункциональная панель на базе Flask для администрирования Linux-серверов. Реализован мониторинг процессов, встроенный файловый менеджер (ZX Explorer), интеграция с Fail2ban и система управления пропускной способностью сети (Traffic Control).

smart_toy

Galactic Soraka

Интеллектуальный Telegram-ассистент, функционирующий на базе нейросетевых моделей (LLM). Система поддерживает удержание контекста диалога, интеграцию с локальными базами данных SQLite и автоматическую маршрутизацию запросов.

dynamic_feed

Ahsoka Ecosystem

Многокомпонентная CRM-система для управления графическим контентом во ВКонтакте. Осуществляет структурированный поиск по внутренней базе данных, управляет отложенным постингом и автоматически формирует расписание публикаций.

video_library

ZX Media Downloader

Telegram-утилита для многопоточной загрузки медиаконтента. Оснащена алгоритмами автоматической записи прямых трансляций с динамическим контролем размера выходного файла для соответствия лимитам мессенджера.

data_exploration

Content Aggregator

Система автоматического парсинга и агрегации графического контента из внешних API. Включает сложную фильтрацию по тегам, кэширование отправленных данных и встроенную конвертацию форматов с использованием подсистемы FFmpeg.

security

ZX Discord Shield

Бот-модератор для серверов Discord. Специализируется на эвристическом анализе сообщений для выявления и моментального удаления фишинговых ссылок, обеспечивая автоматизированную защиту пользователей платформы от вредоносных ресурсов.
